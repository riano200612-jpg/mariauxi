Panel de administración

El panel de Decap CMS se está cargando. Si el botón de login no inicia la autenticación, el problema suele estar en la configuración del backend de GitHub o en el entorno de despliegue.

Para un despliegue real: usa un host que permita la autenticación OAuth de GitHub y asegúrate de que el repositorio y la cuenta tengan permisos de escritura.

En desarrollo local: el login puede no completarse correctamente sin un entorno de autenticación apropiado; en ese caso, usa el flujo de edición mediante GitHub directamente o despliega el sitio en GitHub Pages o Netlify con la configuración correcta.
